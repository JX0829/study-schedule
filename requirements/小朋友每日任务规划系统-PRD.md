# 小朋友每日任务规划系统 - 产品需求文档

**版本：** v1.1  
**更新日期：** 2026-04-16  
**产品经理：** 小品

---

## 一、产品概述

### 1.1 产品定位

面向家庭的儿童任务管理工具，帮助家长科学规划孩子的每日任务，通过积分激励机制培养孩子良好的学习和生活习惯。

### 1.2 核心价值

- **家长端**：便捷配置任务、跟踪完成情况、量化管理孩子成长
- **孩子端**：清晰了解每日任务、获得即时反馈、积分兑换奖励

### 1.3 目标用户

- **主要用户**：有 6-10 岁儿童的家庭（MVP 主打年龄段）
- **使用场景**：家庭日常管理、学习习惯培养、行为激励

> **年龄分层说明：**
> - **6-10 岁（MVP 主打）**：具备基础阅读能力，可独立操作简单界面，理解积分概念
> - **3-5 岁**：需要极简界面、语音提示、家长辅助操作（v1.2 支持）
> - **11-12 岁**：需要社交元素、成就系统、自主规划能力（v1.1 支持）

### 1.4 技术选型

**平台策略：** 先 Web 版，便于迁移至微信小程序

**技术要求：**
- 响应式布局（移动端优先设计）
- 组件化架构（方便复用到小程序）
- 避免使用小程序不支持的 API 和特性
- 使用小程序兼容的 UI 组件库（如支持迁移的设计规范）

## 四、详细功能说明

### 4.1 任务管理模块

#### 4.1.1 任务分类与分值

| 任务类型 | 说明 | 默认分值范围 | 示例 |
|----------|------|--------------|------|
| **作业类** | 学校作业、课外作业 | +5 ~ +20 分 | 完成数学作业 +10 分 |
| **练习类** | 技能练习、兴趣培养 | +3 ~ +15 分 | 钢琴练习 30 分钟 +8 分 |
| **习惯类** | 日常行为习惯 | +3 ~ +10 分 | 主动做家务 +5 分、按时起床 +3 分 |

> **设计理念调整：** 移除"惩罚扣分"，改为"未完成 = 无积分"，避免负面心理影响。如需约束行为，通过"习惯类任务"正向激励。

> 分值可由家长自定义配置

#### 4.1.2 任务模板预设库

**功能描述：** 提供常见任务模板库，家长可一键导入，减少配置成本

**预设分类：**
| 分类 | 模板示例 |
|------|----------|
| **学习类** | 晨读 20 分钟、完成作业、课外阅读 |
| **生活类** | 洗漱、整理房间、按时起床 |
| **兴趣类** | 钢琴练习、画画、运动锻炼 |

**操作：**
- 浏览预设模板库
- 一键导入到我的模板
- 导入后可编辑调整

#### 4.1.3 任务模板管理

**功能描述：** 支持创建可重复使用的任务模板，减少每日配置工作量

**模板字段：**
- 任务名称（必填）
- 任务类型（作业/练习/习惯）
- 默认分值
- 预计时长（分钟）
- 重复规则（每天/工作日/周末/自定义）
- 建议时间段（关联时间段名称）

**操作：**
- 创建模板
- 编辑模板
- 启用/禁用模板
- 删除模板

#### 4.1.4 当日任务规划

**功能描述：** 家长为当天配置具体任务，支持从模板快速添加

**页面布局：**
```

│  📅 2026 年 4 月 16 日 星期四          │
├──────────────────────────────────────┤
│  ☀️ 上午 (06:00-12:00)               │
│  ├─ [ ] 晨读 20 分钟          +5 分   │
│  └─ [ ] 早餐整理              +3 分   │
├──────────────────────────────────────┤
│  🌤️ 放学后 (16:00-18:00)             │
│  ├─ [ ] 数学作业              +10 分  │
│  └─ [ ] 钢琴练习              +8 分   │
├──────────────────────────────────────┤
│  🌙 晚上 (18:00-22:00)               │
│  ├─ [ ] 英语阅读              +8 分   │
│  └─ [ ] 洗漱准备              +3 分   │
├──────────────────────────────────────┤
│  预计总分：37 分    完成进度：0/6     │
└──────────────────────────────────────┘
```

**操作：**
- 从模板添加任务
- 从预设库导入
- 手动添加临时任务
- 调整任务时间段
- 修改任务分值
- 删除任务
- 复制昨日任务

#### 4.1.5 时间段配置

**功能描述：** 支持自定义时间段名称和时间范围，适应不同家庭作息

**默认时间段：**
| 名称 | 时间范围 |
|------|----------|
| 上午 | 06:00-12:00 |
| 下午 | 12:00-18:00 |
| 晚上 | 18:00-22:00 |

**自定义支持：**
- 可添加/编辑/删除时间段
- 每个时间段支持自定义名称（如"放学后"、"睡前"、"午休"）
- 设置开始和结束时间
- 时间段不能重叠

### 4.2 任务执行与确认

#### 4.2.1 孩子端任务视图

**功能描述：** 孩子查看当日任务的简洁界面

**页面元素：**
- 当前时间段任务（高亮显示）
- 已完成任务（灰色 + 勾选标记）
- 待完成任务（正常显示）
- 已完成任务分值累计
- 今日进度条可视化（如：已完成 4/6 任务，进度条显示 67%）

**操作：**
- 点击"申请完成"提交任务
- 查看当前积分余额
- 查看可兑换奖励

#### 4.2.2 任务完成确认流程

**完整流程：**
```
孩子提交完成申请 → 家长收到通知 → 家长确认/驳回 → 积分入账
                                    ↓
                          超时未确认 → 自动确认 + 提醒家长
```

**确认方式：**
- 家长端推送通知
- 家长手动审核确认
- 支持批量确认

**超时处理机制：**
- **超时时间：** 2 小时（可配置）
- **超时动作：** 自动确认通过，积分入账
- **超时提醒：** 推送通知家长"已自动确认任务：XXX"
- **设计目的：** 防止家长忙碌时孩子等待太久，保持激励时效性

**驳回处理：**
- 家长填写驳回原因（必填）
- 孩子收到通知可重新提交
- 驳回后任务状态回到 `pending`

#### 4.2.3 提醒功能

**提醒类型：**
| 提醒类型 | 触发时机 | 接收人 | 说明 |
|----------|----------|--------|------|
| 任务开始提醒 | 任务开始前 5 分钟 | 孩子 | 提醒开始做任务 |
| 任务截止提醒 | 任务结束时间到达 | 孩子 | 提醒任务即将超时 |
| 待确认通知 | 孩子提交完成申请 | 家长 | 推送确认请求 |
| 确认超时提醒 | 超时自动确认后 | 家长 | 告知已自动通过 |
| 每日总结 | 晚上 21:00 | 家长 | 今日完成情况汇总 |

**提醒渠道：** 
- MVP：站内消息 + 浏览器通知（Web Push）
- v1.1：微信模板消息（小程序迁移后）

### 4.3 积分系统

#### 4.3.1 积分规则

**获取积分：**
- 完成任务（家长确认后入账）
- 额外奖励（家长手动发放）
- 连续完成奖励（v1.1）

**消耗积分：**
- 兑换奖励

**积分上限机制：**
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 积分上限 | 最高可累积积分 | 300 分 |
| 超出处理 | 超出上限后无法继续累积 | 提示"已达上限，请兑换奖励" |

> **设计目的：** 防止积分过多导致激励失效，引导孩子定期兑换奖励

**积分有效期：**
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 有效期 | 积分有效时长 | 永久有效（MVP） |
| 清零规则 | 月底清零/季度清零 | v1.1 可配置 |

**积分记录：**
- 每笔积分变动都有记录
- 记录包含：时间、类型、任务名称、分值、余额

#### 4.3.2 积分锁定机制（兑换场景）

**问题背景：** 孩子兑换奖励后，家长驳回，积分扣不扣？

**解决方案：** 积分锁定机制

**兑换流程：**
```
孩子选择奖励 → 提交兑换申请 → 积分锁定（不扣） → 家长确认 → 积分扣除 → 奖励生效
                              ↓
                    家长驳回 → 积分解锁 → 通知孩子
                              ↓
                    超时未确认 → 自动确认 → 积分扣除
```

**锁定规则：**
- 兑换申请时，所需积分进入"锁定状态"
- 锁定积分不能用于其他兑换
- 驳回后锁定积分立即解锁
- 超时时间：24 小时（兑换场景需要家长有时间安排）

#### 4.3.3 奖励兑换

**奖励管理：**
- 家长创建可兑换奖励
- 设置所需积分
- 设置库存数量（可选）
- 设置使用规则（如"周末可用"、"每月限 1 次")

**奖励示例：**
| 奖励名称 | 所需积分 | 库存 | 使用规则 |
|----------|----------|------|----------|
| 看动画片 30 分钟 | 20 分 | 无限 | 周末可用 |
| 买小玩具 | 100 分 | 1 | 每月限 1 次 |
| 去游乐园 | 200 分 | 1 | 需提前预约 |

### 5.2 状态枚举

**任务状态 (daily_tasks.status)：**
- `pending` - 待开始
- `in_progress` - 进行中
- `submitted` - 已提交（待确认）
- `completed` - 已完成
- `rejected` - 已驳回
- `expired` - 已过期（未在时间段内完成）

**兑换状态 (redemption_records.status)：**
- `pending` - 待确认（积分已锁定）
- `approved` - 已通过（积分已扣除）
- `rejected` - 已驳回（积分已解锁）

**积分变动类型 (points_records.change_type)：**
- `earn` - 获取（任务完成）
- `bonus` - 额外奖励
- `redeem_lock` - 兑换锁定
- `redeem_unlock` - 兑换解锁（驳回）
- `redeem_deduct` - 兑换扣除

## 七、非功能性需求

### 7.1 性能要求

- 页面加载时间 < 2 秒
- 支持并发用户数 ≥ 1000

### 7.2 数据安全

- 用户数据按家庭隔离
- 敏感信息加密存储
- 操作日志记录

### 7.3 兼容性（Web + 小程序迁移）

**Web 版兼容性：**
- 支持主流浏览器（Chrome、Safari、Edge）
- 支持移动端响应式布局
- 支持 Web Push 通知

**小程序迁移友好：**
- 使用小程序兼容的 UI 组件库
- 避免 DOM 直接操作，使用状态驱动渲染
- 避免使用 localStorage，使用统一存储抽象层
- 图片/图标使用小程序兼容格式
- API 请求封装为统一接口层，便于替换

### 7.4 可用性

- 系统可用性 ≥ 99%
- 支持数据备份和恢复
